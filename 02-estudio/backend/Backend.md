El backend es el motor invisible de cualquier aplicación. Es toda la infraestructura lógica y bases de datos que operan "detrás de escena" para el usuario final pueda hacer lo que necesita en la pantalla (el Frontend)


##### Herramientas comunes
- **Lenguajes**: Java, Python, Node.js, Go etc.
- **[[Bases de datos]]**: PostgreSQL, MySQL, MongoDB
- **Infraestructura**: Servidores Linux, AWS, Docker
